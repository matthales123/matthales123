## Featured projects

### [Systolic Matrix Multiplication](https://github.com/matthales123/u55c-systolic-mmul)

Cornell SysBase RTL adapted to Alveo U55C, with AXI integration, UVM tests, scoped formal checks, and documented hardware validation.

**Validated pilot:** two UVM seeds, scoped formal checks, and 48 U55C hardware runs across matrix dimensions 1–8. The project README documents the tested configuration and verification limits.

### [Mandelbrot Explorer](https://github.com/matthales123/u55c-mandelbrot-explorer)

RTL/HLS Mandelbrot kernels, multi-compute-unit XRT scheduling, and a local interactive workbench.

### [FPGA Drum Synthesis](https://github.com/matthales123/ece5760-drum-synth)

Finite-difference drum simulation with FPGA computation, HPS control, and audio applications.
